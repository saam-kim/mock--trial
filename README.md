# ⚖️ 사건수첩: 판결의 조건 (Mock Trial Simulator)

> **헌법상의 영장주의와 위법수집증거 배제 원칙을 배우는 실시간 모의재판 협동 시뮬레이터**  
> 학생들은 검사, 변호인, 배심원 역할을 맡아 실시간으로 소송 서면을 작성하고, 제출된 증거의 적법성을 다투며 정의로운 평결을 내려봅니다.

---

## 📌 프로젝트 소개

**사건수첩: 판결의 조건**은 학교 수업 및 교육용으로 설계된 **실시간 모의재판 시뮬레이터**입니다.  
사건의 이면에 감춰진 적법과 위법의 경계를 탐색하며, 학생들이 헌법 제12조 제3항(영장주의) 및 형사소송법 제308조의2(위법수집증거 배제 원칙) 등 형사사법의 핵심 가치를 능동적이고 상호작용이 가득한 게임 형태로 학습할 수 있도록 돕습니다.

---

## ✨ 주요 기능

| 기능 | 상세 설명 |
| :--- | :--- |
| **🔑 교사용 관리 대시보드** | 세션 코드를 발급하여 클래스를 개설하고, 학생들의 역할을 드래그 앤 드롭으로 배정하며, 단계(도입~평결) 강제 전환 및 타이머를 제어합니다. |
| **👥 실시간 역할군 협업** | **검사 측**(기조대변인, 증거분석관, 반박전략가, 최종변론가)과 **변호인 측**(기조답변인, 증거감시관, 방어논증가, 최종변론가)으로 나뉘어 실시간으로 법정 공방 서면을 작성합니다. |
| **🚨 실시간 이의제기 (Objection)** | 검사 측이 증거를 제출하면, 변호인 측(증거감시관)이 실시간으로 수집 절차 상의 법적 하자를 검토하고 **이의제기**를 신청할 수 있습니다. 교사(재판장)는 이를 인용(배제)하거나 기각(채택)합니다. |
| **💬 배심원단 관전 피드** | 배심원단은 법정 공방 실시간 피드를 보며 의견을 남기고 관전평을 작성하며, 최종 평결 단계에서 피고인의 유/무죄 투표를 진행합니다. |
| **🖨️ 모의재판 판결문 인쇄** | 재판이 종료되면 최종 결과(양측 서면, 이의제기 기록, 배심원 투표 결과 등)를 법원 판결문 양식으로 정리하여 PDF 다운로드 및 인쇄할 수 있습니다. |

## 🛠️ 기술 스택

* **Frontend**: Vanilla HTML5, Modern ES6+ JavaScript, CSS3 Variables
* **Design System**: Glassmorphism UI, Dark Mode Optimized Color Palette, Responsive Layout
* **Database & Sync**: 
  * `BroadcastChannel API`: 별도 서버 없이 동일 PC/브라우저 내 다중 탭 간 실시간 1:1 동기화 제공 (기본 모드)
  * `Firebase Realtime Database`: 여러 디바이스 간 원격 실시간 동기화 확장 지원

## 🚀 사용 방법

### 1. 로컬 환경에서 실행하기
이 프로젝트는 별도의 빌드 단계가 필요 없는 Pure Vanilla HTML/JS 프로젝트입니다.  
프로젝트 폴더 내 `index.html` 파일을 더블 클릭하여 바로 실행하거나, 로컬 서버(예: Live Server, `http-server` 등)를 통해 띄울 수 있습니다.

### 2. 모의재판 진행 흐름
1. **세션 개설 (교사)**
   * 메인 화면 좌측 하단에서 `🔑 교사용 대시보드로 입장하기`를 클릭합니다.
   * 교사 인증 PIN 번호(임의의 4자리)를 입력하여 대시보드를 개설하고 **6자리 세션 코드**를 확인합니다.
2. **학생 입장 및 역할 배정**
   * 학생들은 다른 브라우저 탭(또는 다른 기기)에서 세션 코드와 이름을 입력하고 대기실에 입장합니다.
   * 교사는 대기 학생 목록을 확인하고 자동 배정 또는 드래그 앤 드롭을 통해 각 역할을 지정합니다.
3. **사건 스토리 확인 (1단계)**
   * 교사가 재판을 시작하면 피해자 이서아와 피고인 강지민의 스토리가 비주얼 노벨 형식으로 연출됩니다.
4. **기조진술 및 서면 작성 (2단계)**
   * 양측 기조 담당자가 공소사실 및 답변서를 작성하여 제출합니다.
5. **증거 조사 및 이의제기 (3단계)**
   * 검사 측이 증거 마켓에서 증거를 제출하면, 변호인 측은 실시간으로 이의제기(Objection)를 신청하여 위법하게 수집된 증거의 배제를 이끌어내야 합니다.
6. **공방 및 최종변론 (4~5단계)**
   * 쟁점에 대해 논증하고 반박문을 작성하며 배심원들을 설득합니다.
7. **평결 및 판결 (6단계)**
   * 배심원단이 유/무죄 여부를 투표하고, 최종 투표 결과와 작성 기록을 바탕으로 판결 보고서를 출력합니다.

## ⚖️ 학습용 법리 안내 (시나리오 내 포함)

시뮬레이션 중 다음과 같은 실제 헌법 및 법률 조항을 학습하고 적용할 수 있습니다.
* **헌법 제12조 제3항 (영장주의)**: 강제수사 시 적법절차 및 판사가 발부한 영장 제시 원칙.
* **형사소송법 제308조의2 (위법수집증거 배제 원칙)**: 적법 절차를 위반해 수집한 증거의 증거능력 부정.
* **통신비밀보호법 제3조**: 동의 없는 제3자 간의 사적인 비밀 녹음 및 도청 증거 사용 제한.
* **형사소송법 제309조 (자백배제법칙)**: 고문, 협박, 감금 등 임의성 없는 자백의 증거능력 부정.
